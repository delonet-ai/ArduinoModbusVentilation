# Hardware validation checklist

Эта проверка обязательна перед выпуском прошивки на реальное оборудование. Программная сборка не заменяет испытание питания, механики и линии RS-485.

## Direct backend

- [ ] Nano загружается с подключённым RS-485 либо задокументирована необходимость отключать `RX`/`TX` при прошивке.
- [ ] Физические каналы `0..9` управляют пинами `D8`, `D9`, `D10`, `D11`, `D12`, `A0`, `A1`, `A2`, `A3`, `A4` в указанном порядке.
- [ ] После холодного старта нет промежуточного полного хода заслонок.
- [ ] Команды `0%`, `50%`, `100%` не выводят механику за безопасные пределы.
- [ ] Одновременное движение десяти серв не сбрасывает Nano и не нарушает Modbus.

## PCA9685 backend

- [ ] PCA9685 доступен по адресу `0x40`; `SDA=A4`, `SCL=A5`.
- [ ] Каналы PCA9685 `0..4` управляют вытяжкой, `5..9` — притоком тех же комнат.
- [ ] Внешнее питание выдерживает суммарный пусковой ток, все земли объединены.
- [ ] Импульсы `0%`, `50%`, `100%` отличаются от direct-варианта не более чем на один тик PCA9685.
- [ ] При отключении I²C загорается встроенный LED, Modbus остаётся доступным.
- [ ] После восстановления I²C драйвер возобновляет работу не позднее чем через пять секунд.

## Защита расхода и WB

- [ ] В WB отображаются ровно пять комнатных ползунков, без отдельных ползунков притока и вытяжки.
- [ ] Один комнатный ползунок одинаково изменяет физические заслонки вытяжки и притока выбранной комнаты при повышении и понижении.
- [ ] При попытке установить все комнаты в `0%` ползунки спальни и детской автоматически возвращаются к `100%`.
- [ ] Суммы притока и вытяжки в диагностике никогда не опускаются ниже `200%`.
- [ ] При сумме пользовательских уставок `200%` или выше применённые значения совпадают с заданными, флаг коррекции равен `0`.
- [ ] После перезагрузки восстанавливаются пользовательские значения и повторно применяется защита расхода.
- [ ] Включение режима камина открывает только приточные клапаны кухни и гостиной на `100%`.
- [ ] Выключение режима камина возвращает приток кухни и гостиной к прежним пользовательским уставкам.
- [ ] После перезагрузки Arduino режим камина выключен.
- [ ] WB-шаблон не показывает внутренние регистры применённых физических каналов `5..14` и флаг `17`.

## Release gate

Не создавать hardware-релиз, пока все пункты нужного backend не отмечены и не записаны фактические модели серв, диапазоны импульсов и параметры источника питания.
